## Project Reflection
If I were to give myself advice for creating a similar type of project in the future, I would say that it is important to have a detailed outline for every sigle feature that I want to add. Although my "needs to have" list gave me a good general idea of all the things I wanted to implement, the specifcs of it all were all done as I went. It is inevitable that I will have new ideas pop up after initially starting, but I believe that a more specified planning document could help me better manage my time and make it easier to plan my workload. 

I am very happy in having completed everything in my needs to have list. This is a result of setting a goal that was not impossible but yet challenging at the very beginning of my project. However, my nice to have list is a bit more ambitious, as the only thing that I have been able to implement was the different background options.

The hardest part of my project was the object-oriented programming portion of my code. I made many classes and sub-classes, including characters and projectiles and much more. Having to wrap my head around all the different class functions, class properties and inheritance was very challenging. In the beginning, I was having a hard time figuring out when to use this.health or birdship.health, for example. Calling the projectile class functions inside the characters class functions was also something that initially appeared confusing to me. Aside from objected-oriented programming, getting all the images took longer then I thought it would. For each individual charcter and projectile, I had to flip them in the right directions, make the image backgrounds transparent, and also crop the image so that the hitboxes would be represented better.

There were no problems in my project that I could not solve. I ran into problems often, but all that needed to be done was work through them carefully and sometimes try to solve them in a different way. For example, my birdship had a bug where it would shoot once whenever the player clicks from the main meni to start the game. All I had to implement was a boolean that detects if the birdship was spawned before it can start shooting.
